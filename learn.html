Learn INTERCAL in 17 Steps

The samples/learn-intercal/ folder contains 17 tiny programs, one per language feature. Each is heavily commented and designed to be stepped through in the debugger. Open a file, set a breakpoint on the first line, press F5, and start stepping.

Tip: Open the Variables panel and Watch panel side by side. The comments in each program tell you what to look for as you step.

Lessons

04select.iThe select operator (~) — bit extraction with masks

07next-resume.iSubroutine calls with NEXT and RESUME
08forget.iFORGET — dropping the return address (one-way trip)
09abstain-reinstate.iDisabling and re-enabling statements
10come-from.iCOME FROM — the opposite of GOTO
11stash-retrieve.iSaving and restoring variable state
12ignore-remember.iRead-only variables
13please.iPoliteness requirements (yes, really)
14arrays.iTails, hybrids, and SUB indexing
15syslib.iArithmetic via the system library
16write-in.iUser input (yes, WRITE IN reads and READ OUT writes)
17come-from-loop.iLooping with COME FROM

Quick Reference

Statements

StatementWhat It Does
DO .1 <- #42Assign (CALCULATE)
DO (100) NEXTCall subroutine at label 100
DO RESUME #1Return from subroutine
DO FORGET #1Drop return address
DO COME FROM (100)Hijack control after label 100
DO ABSTAIN FROM (100)Disable statement at label 100
DO REINSTATE (100)Re-enable statement at label 100
DO STASH .1Save .1 on its stash stack
DO RETRIEVE .1Restore .1 from its stash stack
DO IGNORE .1Make .1 read-only
DO REMEMBER .1Make .1 writable again
DO READ OUT .1Print value (yes, READ OUT writes)
DO WRITE IN .1Read input (yes, WRITE IN reads)
PLEASE GIVE UPExit program
